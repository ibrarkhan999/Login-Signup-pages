# 🔑 Login & Signup Pages

### A clean, ready-to-connect authentication UI.

A simple and elegant front-end template for login and signup pages, built with **React Native**. Provides a clean UI for authentication forms that can later be connected to a backend server.

## 🎨 How It Works

| Step | Action |
|:----:|--------|
| 1️⃣ | User lands on the **Login** screen |
| 2️⃣ | New users tap through to **Signup** |
| 3️⃣ | Form inputs are validated client-side |
| 4️⃣ | Submit hooks are ready to wire up to your backend |

## 🚀 Getting Started

### Prerequisites

| Requirement | Version |
|:--|:--|
| Node.js | `>= 18` |
| Yarn / npm | latest |
| Android SDK | latest |

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/Login-Signup-Pages.git

# Navigate to project
cd Login-Signup-Pages

# Install dependencies
yarn install

# Run on Android
yarn android

# Run on iOS
yarn ios
```

<br>

## 🔌 Connecting a Backend

This template ships with UI only — no auth logic included. To wire it up:

1. Add your API calls in the form submit handlers
2. Store auth tokens securely (e.g. with `react-native-keychain` or `AsyncStorage`)
3. Add protected routes/navigation once a user is authenticated
